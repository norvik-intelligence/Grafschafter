# Grafschafter Alltagsservice

Responsive, static website for Grafschafter Alltagsservice in Moers.

## Local preview

Open `index.html` directly in a browser, or run `npx serve .`.

## Before launch

- Replace the placeholder telephone number with the final business number.
- Replace footer placeholders for Impressum and Datenschutz with legally reviewed pages and complete TMG details.
- Confirm recognition status and the permitted billing paths with the relevant authority / Pflegekasse before advertising direct billing.
